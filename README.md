Assignment: HW4 - Blackjack Solitaire

Partner: None.

How to run:
Compile all .java files and run BlackjackSolitaireRunner.

Files:
- Card.java: represents a single playing card (rank, suit, point value).
- Deck.java: represents a standard 52-card deck; creates, shuffles, and deals cards.
- BlackjackSolitaire.java: include method for overall play procedure, board setting, user input, and scoring.
- BlackjackSolitaireRunner.java: contains the main method that starts the game.
